# Runbooks

Operational runbooks will be completed during Milestones 8–9. Required topics:

- deployment and rollback;
- Salesforce outage, timeout, rate limit, and quota exhaustion;
- Cognito user provisioning, disablement, and incident response;
- Salesforce credential/key rotation and revocation;
- suspected secret or token exposure;
- alarm triage and safe log investigation;
- environment cleanup with retention safeguards.

Each runbook must identify owner, prerequisites, safety checks, exact procedure, verification, rollback/escalation, and last exercise date. Do not include real identifiers, credentials, Account payloads, or customer data.
